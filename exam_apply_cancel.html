시험취소 방법

시험 취소 방법
취소 기간 내 : 본인이 직접 취소 가능
취소 기간 이후 : 취소만 가능 (단, 취소 품의 결재 건에 한함)

[취소기간 이후 시험 취소 품의 방법]

  1. 작성양식 : LGEP → Request → '역량인증' 검색 → [AI SW 역량인증시험] 시험 취소 요청 품의
  2. 결재자 : 조직책임자

결시자 안내

시험 당일_결시자 안내
시험 취소 없이 시험 당일 결시자는 회사지원 시험 응시 횟수 차감(25년 2차 시험부터 적용)됩니다.

단, 업무, 경조사 등의 불가피한 사유로 인한 불참인 경우,
조직책임자의 결재를 통해 회사지원 시험 응시 횟수 차감 면제받으실 수 있습니다.

[결시자 응시횟수 차감 면제 품의 방법]

  1. 작성양식 : LGEP → Request → '역량인증' 검색 → [AI SW 역량인증시험] 결시자 패널티 면제요청 품의
  2. 결재기한 : SW역량강화팀에서 안내 받은 기한 내 품의 완료된 건에 한해 적용 함
  3. 결재자 : 조직책임자
